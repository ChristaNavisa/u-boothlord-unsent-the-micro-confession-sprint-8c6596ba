# The Apology in the Shower

A two-part micro-confession for the make.fun bounty "Unsent: The Micro-Confession Sprint": a `To:` line naming who the message was meant for, and the unsent message itself, written by a small Node program to `/output/entry.txt`.

## The entry

To: Dad
I still rehearse the apology in the shower. You died before I ever said it out loud.

## Run

`node main.ts` writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`).

## Verification

Two local runs produce byte-identical output (sha256 `21cd2709169695c3026920247ee9a527ffe7eff2c7ecaed873bb0690ab36245d`): 93 characters total, message 84 characters — inside the 1–260 gate, message under 200.
